# 急性腦中風衛教互動指南

參考使用者既有肌少症衛教網站，以暖色、大字、主題輪播與卡片內容呈現。適用一般民眾與家屬；沒有帳號、資料上傳、外部圖片、字型依賴或個人治療資格計算。

## 開啟

直接用瀏覽器開啟本資料夾的 `index.html`，即可離線使用。或在 PowerShell 切換至下載的專案資料夾後執行：

```powershell
node preview.cjs
```

開啟 <http://127.0.0.1:4173>。本機伺服器只接受本機連線；以 Ctrl+C 停止。不需要安裝套件。

## 內容與互動

- 首頁三個手動切換主題、不自動輪播，避免干擾閱讀。
- FAST 警訊、其他症狀及 119 緊急應對。
- 三個治療流程分頁，可用方向鍵、Home／End 操作。
- 照護重點展開、返家前清單及列印。
- 三題情境練習，每題提供解說；成績只代表這次知識練習。
- 手機導覽、放大字級、鍵盤焦點、減少動態偏好。

勾選及測驗僅存在當次頁面記憶體，重新整理會重設。所有 `tel:119` 連結會交由裝置的電話功能處理，使用者仍需確認撥出。桌機若沒有電話程式，請直接使用手機撥打 119。

資料來源列於網站頁尾；查閱日期 2026-10-17。網站為一般衛教，正式臨床使用前仍需使用單位醫護審閱。GitHub 原始碼同步與網站公開部署分開處理，本專案未啟用 GitHub Pages。

## 驗證

沒有依賴套件、建置程序或既有測試框架。已執行 `node --check app.js` 與 `node --check preview.cjs`，皆通過；本機首頁回應 HTTP 200。

瀏覽器已檢視 1265px 桌面與 507px 窄螢幕畫面，並修正 840px 寬度下的裝飾溢出。已操作主題切換、頁內導覽、三種治療分頁、三題測驗（故意答錯一題，結果為 2/3）、重新練習、兩項清單勾選計數、字級切換與重新整理重設。這些是製作時的驗證紀錄，後續修改仍需重新檢查。
